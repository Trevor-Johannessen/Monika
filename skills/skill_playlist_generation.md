# Playlist Generation

When the user asks for a playlist or song recommendations — explicitly ("make me a playlist") or implicitly ("I want something chill", "put on something to work to") — read their listening profile and generate a mood-aware pick list. Hand the tracks off to the spotify skill if they want them played or queued.

## Where the data lives

All files are under `scripts/spotify/` (relative to the current working directory):

- `SPOTIFY_CONTEXT.md` — the main reference (recent sessions, mood archetypes, anchor/avoid tracks, mood-sensitive artists, reliable favorites, global skips, trend signals). Read this first.
- `PLAYLIST_AGENT_GUIDE.md` — the procedure to follow.
- `artist_cooccurrence.json` — neighbors for any given artist (use only if you need to fill slots beyond the anchor list).
- `mood_archetypes.json` — full archetype details including more anchor tracks per archetype than `SPOTIFY_CONTEXT.md` shows.
- `preference_profile.json` — full preference profile (top liked artists, trends, reliable tracks, reliable skips).

For most requests, `SPOTIFY_CONTEXT.md` alone is enough.

## How to build the playlist

1. Match the user's current mood to the closest archetype. If they named a vibe ("chill", "upbeat", "nostalgic"), pick the archetype whose representative artists fit. Otherwise use the "Current Mood Match" line in `SPOTIFY_CONTEXT.md`.
2. Use that archetype's anchor tracks as the core (5–7 tracks).
3. Fill remaining slots with Reliable Favorites and artists that co-occur strongly with the archetype's representative artists.
4. Exclude that archetype's avoid tracks AND the Global Consistent Skips.
5. For Mood-Sensitive Artists, only include them if the current mood matches their listed `fits` archetype.
6. Prefer rising artists over fading ones when multiple options fit.
7. Aim for 10–15 songs total; include at least 3 anchor tracks.

## What to do with the picks

- If the user wants the music played or queued ("put something on", "play me a playlist"), call the spotify skill's queue endpoint for each track URI, then start playback on the first one.
- If the user just wants suggestions ("what should I listen to", "recommend some songs"), tell them the picks conversationally and stop there.

## Response style

Reply in short, natural sentences suitable for TTS. No markdown lists, no Spotify URIs read aloud, no archetype labels like "archetype_4" — translate them into plain descriptions of the vibe ("a Sara Bareilles-leaning singer-songwriter set", "a 2000s pop-punk run"). Mention 2–3 of the picks by name and artist; do not recite the whole list aloud. If you queued the tracks, just confirm briefly.

## Keeping the profile fresh

The profile is regenerated by running three scripts in `scripts/spotify/`:

1. `parse_sessions.py`
2. `analyze_correlations.py`
3. `generate_context.py`

Use `/mnt/fs1/apps/venvs/ml/bin/python` to run them. The pipeline takes a few seconds total. If the user says the profile feels stale, or asks for a refresh, run all three.
